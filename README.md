# Scapy Projects

A collection of Python projects developed using [Scapy](https://scapy.net/), focused on networking, packet crafting, and protocol analysis.

This repository serves as a personal portfolio of practical projects created while studying computer networking and cybersecurity.

## Projects

### PyDNS Inspector
A DNS query and response inspection tool built with Python and Scapy.

- DNS queries over UDP
- Multiple DNS record types
- Response code interpretation
- DNS answer record inspection

[View Project](./pydns-inspector)

### NsPyLookup
A Python-based networking project developed using Scapy.

[View Project](./NsPyLookup)

## Technologies

- Python
- Scapy
- DNS

- Network Protocol Analysis
